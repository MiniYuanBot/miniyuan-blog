## 一、物理层概述

### 1.1 OSI 定义与核心功能

本质上就是：屏蔽传输媒体的差异，为上层提供统一接口。

**物理层**的功能是在物理介质上传输**数据比特流**，定义信号在信道上发送所需的**机械、电气、时序和接口**特性。

**提供的服务**：
- 发送和接收比特流的能力（连接的建立、维持和释放）
- 在两个相邻通信结点之间唯一地标识数据电路

### 1.2 关键特性

| 特性 | 说明 |
|:---|:---|
| **机械特性** | 接线器的形状、尺寸、引线数目和排列、固定和锁定装置 |
| **电气特性** | 接口电缆各条线上出现的电压范围 |
| **功能特性** | 某条线上某一电平电压的意义 |
| **过程特性** | 不同功能的各种可能事件的出现顺序 |

## 二、数据通信基础

### 2.1 数据通信系统模型

```
信源 → [发送器] → 信道(含噪声) → [接收器] → 信宿
```

**三大部分**：
- **源系统**：产生要传输的数据
- **传输系统**：传输线路或网络
- **目的系统**：接收并处理数据

### 2.2 核心术语

| 术语 | 定义 |
|:---|:---|
| **数据(data)** | 运送消息的实体（比特序列） |
| **信号(signal)** | 数据的电气或电磁表现 |
| **模拟信号** | 代表消息的参数取值**连续** |
| **数字信号** | 代表消息的参数取值**离散** |
| **码元(code)/符号** | 一个周期脉冲信号，可以利用它的不同状态（振幅）代表多个比特 |
| **信道** | 向某一个方向传送信息的媒体 |

### 2.3 主要性能参数

| 参数 | 符号/单位 | 说明 |
|:---|:---|:---|
| 信号功率 | S (W/mW) | - |
| 信道带宽 | B (Hz) | 与收发设备及传输介质特性有关 |
| 噪声功率 | N (W) | 通信线路上的平均噪声功率 |
| **信噪比** | SNR = S/N 或 SNR<sub>dB</sub> = 10log₁₀(S/N) | 10dB=10倍，20dB=100倍，3dB=2倍 |
| **数据率** | bps | 单位时间传输的比特数 |
| **误码率** | 1×10⁻ⁿ | 数据传输的错误概率 |

### 2.4 通信方式分类

| 方式 | 英文名 | 特点 |
|:---|:---|:---|
| **单工通信** | Simplex | 只能单向传输，无反方向交互 |
| **半双工通信** | Half-duplex | 双方可发送，但不能同时发送/接收 |
| **全双工通信** | Full-duplex | 双方可同时发送和接收 |

## 三、通信理论基础

### 3.1 离散时间傅里叶变换

本质上是进行数字脉冲信号（离散、时域）和模拟物理信号（连续、频域）之间的转换。

周期为 $T$ 的信号 $g(t)$ 可表示为基频 $f=\frac{1}{T}$ 的若干次谐波分量叠加，并且叠加次数越多拟合越精确。从而：
- $ 基频 \times 谐波数 = 信道带宽 $
- $ 基频 \times 每码元比特数 = 数据率 $
- 信道带宽越宽，可通过的谐波数量越多，信号保真度越好，数据率越高。
- 数据率越大（谐波数越少）/信号传输距离越远/传输媒体质量越差，信号失真越严重。

### 3.2 奈奎斯特定理（Nyquist）

**理想无噪声信道**下的最大数据率：
$$C = 2B \log_2 V$$

- **B**：信道带宽(Hz)
- **V**：信号状态数
- **波特率/码元速率** = 2B

**注**：奈氏准则没有限制码元传输的比特数。

> **采样原理**：码元传输速率有上限，否则出现**码间串扰**。采样率需为信号最高频率的2倍才能重构原信号。

### 3.3 香农定理（Shannon）

**有噪声信道**的极限信息传输速率：
$$C = B \log_2(1 + \frac{S}{N}) \quad \text{(b/s)}$$

**注**：
- 带宽B或信噪比S/N越大，极限传输速率越高
- 只要实际速率 $\lt$ C，理论上就可实现无差错传输
- 实际速率通常远低于香农极限
- [后两个定理之间的关系](https://www.zhihu.com/question/298994995)

### 3.4 传输同步方式

| 特性 | **异步传输** | **同步传输** |
|:---|:---|:---|
| **传输单位** | 字符 | 帧（数千比特） |
| **时钟同步** | 收发时钟不同源 | 时钟同源或从信号中提取 |
| **开销** | 每字符含起始位、数据、校验位、停止位 | 包含帧首尾标志、数据，效率高 |
| **适用场景** | 低速传输（如RS-232） | 长距离高速传输 |
| **特点** | 简单、廉价，可能有采样误差 | 需时钟线或时钟提取，效率高 |

## 四、编码与调制技术

### 4.1 基带调制（编码）

本质上是将数据（01比特流）转换为数字脉冲信号（仍是基带信号），且**不改变频带**：

| 编码方式 | 规则 | 特点 |
|:---|:---|:---|
| **RZ** (归零码) | 高电平=1，低电平=0 | 无自同步能力，连0/1问题，DC分量 |
| **NRZ** (非归零码) | 高电平=0，低电平=1 | 无自同步能力，连0/1问题，DC分量 |
| **NRZI** (非归零反转) | 跳变=1，无跳变=0 | 差分编码，解决连1问题，仍有连0问题 |
| **曼彻斯特编码** | 位中心上跳=0，下跳=1 | 每比特必跳变，**自同步**，带宽效率B |
| **差分曼彻斯特** | 位中心必跳变，位边界跳变=0 | 抗干扰强，自同步，带宽效率B |
| **4B/5B编码** | 4比特映射为5比特 | 解决连0问题，用于100Mbps以太网 |

**带宽效率对比：**
- NRZ/NRZI：数据率 = 2B（奈奎斯特极限）
- 曼彻斯特/差分曼彻斯特：数据率 = B（牺牲带宽换同步）

### 4.2 带通调制

使用**载波**将基带信号频谱搬移到较高频段，适用于模拟信道：

| 调制方式 | 调制参数 | 特点 |
|:---|:---|:---|
| **ASK** (调幅) | 振幅A变化 | 抗干扰能力弱 |
| **FSK** (调频) | 频率f变化 | 抗干扰优于ASK，频带利用率不高 |
| **PSK** (调相) | 相位Φ变化 | BPSK：0和π相位表示0和1 |
| **QPSK** | 4种相位(45°,135°,225°,315°) | 每符号2比特 |
| **QAM** (正交振幅调制) | 幅度+相位联合调制 | QAM-16:4比特/符号，QAM-64:6比特/符号 |

**星座图**：将数字信号表示在复平面上，展示信号点间的距离关系。

> **权衡**：码元状态数越多，数据率越高，但接收端识别难度增大，误码率上升。

## 五、信道复用技术

### 5.1 复用概述

**复用(Multiplexing)**：多路信号共享同一传输介质，提高利用率。

### 5.2 频分复用（FDM）

- **原理**：用户分配到不同频带，**同时**传输，频带互不重叠
- **保护间隔**：子信道间设保护带（滤波器非理想矩形）
- **应用**：广播系统、电话系统、电视系统、ADSL

**电话系统FDM层级：**
- 12路话音(4kHz) → 群(48kHz)
- 5个群 → 超群(240kHz，60路)

### 5.3 时分复用（TDM）

- **原理**：时间划分为等长TDM帧，每用户占用固定序号时隙，**分时**占用相同频带
- **同步要求**：用户间需严格同步，时隙间设保护间隔
- **问题**：计算机数据突发性强，固定时隙可能造成**线路资源浪费**

**统计时分复用（STDM）**：
- 按需动态分配时隙，提高线路利用率
- 帧长不固定，需地址标识

### 5.4 码分复用（CDM/CDMA）

- **原理**：各用户使用**正交码片序列**，同时同频传输
- **码片序列**：m位序列，发送1送原码，发送0送反码
- **正交性**：不同用户码片序列内积为0，自身规格化内积为1

**关键特性：**
- **扩频通信**：码片速率 = m × 数据率，频谱展宽m倍
- 抗干扰能力强，保密性好（类似白噪声频谱）
- 需严格功率控制

**应用**：3G移动通信系统

### 5.5 波分复用（WDM）

- **本质**：光的频分复用
- **技术**：单根光纤传输多个光载波信号（如8×2.5Gbps）
- **EDFA**：掺铒光纤放大器，同时放大多路光信号

### 5.6 正交频分复用（OFDM）

- **特点**：子载波**正交**，无保护间隔，频谱效率最高
- **实现**：IFFT/FFT，子载波数可变，调制方式可变（自适应）
- **应用**：4G/5G、Wi-Fi

## 六、传输介质

### 6.1 有线传输介质对比

| 介质 | 频率范围 | 典型衰减 | 中继间距 | 特点 |
|:---|:---|:---|:---:|:---|
| **双绞线(加载)** | 0-3.5 kHz | 0.2 dB/km@1kHz | 2 km | 成本低，易安装，抗干扰一般 |
| **双绞线(多对)** | 0-1 MHz | 0.7 dB/km@1kHz | 2 km | 数字传输，100m典型距离 |
| **同轴电缆** | 0-500 MHz | 7 dB/km@10MHz | 1-9 km | 抗干扰好，50Ω(数字)/75Ω(模拟) |
| **光纤** | 186-370 THz | 0.2-0.5 dB/km | 40 km | 容量大，损耗小，抗电磁干扰 |

### 6.2 双绞线标准（EIA/TIA-568）

| 类别 | 带宽 | 应用 |
|:---:|:---:|:---|
| 3类 | 16 MHz | 模拟电话，传统以太网(10Mbps) |
| 4类 | 20 MHz | 令牌局域网 |
| 5类 | 100 MHz | ≤100Mbps应用 |
| 5E(超5类) | 125 MHz | ≤1Gbps应用 |
| 6类 | 250 MHz | >1Gbps应用 |
| 7类 | 600 MHz | >10Gbps应用，屏蔽双绞线 |

### 6.3 光纤

**结构**：纤芯（高折射率）→ 包层 → 保护层

**传输原理**：全反射（入射角>临界角）

| 类型 | 特点 | 应用 |
|:---|:---|:---|
| **多模光纤** | 多条光线不同角度传输，纤芯较粗(50μm) | 短距离，LED光源 |
| **单模光纤** | 直径=光波长，直线传播无反射，纤芯细(9μm) | 长距离，激光光源 |

**常用波段**：850nm、1300nm、1550nm（带宽25,000-30,000 GHz）

**优点**：容量极大、损耗小、中继距离长、抗电磁干扰、保密性好、体积小重量轻

### 6.4 无线传输介质

| 频段 | 特性 | 应用 |
|:---|:---|:---|
| 30MHz-1GHz | 全向性 | 无线电广播 |
| 2GHz-40GHz | 方向性增强 | 微波中继、卫星通信 |
| 3×10¹¹Hz-2×10¹⁴Hz | 视距传播 | 红外线、激光、可见光 |

**微波通信特点**：
- 直线传播（LOS），100m高塔中继约80km
- 多径干扰、雨衰（高频段）
- 路径损耗随距离指数衰减

**卫星通信**：
- **地球同步卫星**：36000km，时延约120ms，广播信道
- **频段**：C波段(4/6GHz)、Ku波段(11/14GHz)、Ka波段(20/30GHz)
- **低轨卫星**：750km高度，L波段(1.6GHz)，用于定位/移动通信

## 七、通信系统实例

### 7.1 电话系统（PSTN）

**组成**：
- **本地环路**：模拟双绞线（用户→端局），独占线路
- **干线**：交换局之间，高速数字信道（光缆）
- **交换局**：电路交换或分组交换转接

**数字化演进**：
- PDH（准同步数字系列）→ SDH/SONET（同步数字系列）

| 标准 | 速率 | 结构 |
|:---|:---|:---|
| **T1** | 1.544 Mbps | 24信道×8bit+1帧标志，125μs帧长 |
| **E1** | 2.048 Mbps | 32信道×8bit，30路话音+2路控制 |

**SONET/SDH速率等级：**

| 线路速率 | SONET | SDH | 常用近似值 |
|:---:|:---:|:---:|:---:|
| 51.840 Mbps | OC-1/STS-1 | - | - |
| 155.520 Mbps | OC-3/STS-3 | **STM-1** | 155 Mbps |
| 622.080 Mbps | OC-12/STS-12 | STM-4 | 622 Mbps |
| 2.488 Gbps | OC-48/STS-48 | STM-16 | 2.5 Gbps |
| 9.953 Gbps | OC-192/STS-192 | STM-64 | 10 Gbps |
| 39.813 Gbps | OC-768/STS-768 | STM-256 | 40 Gbps |

> **OC-3用户数据率计算**：155.52 Mbps × (260/270) = **148.608 Mbps**（扣除开销）

### 7.2 宽带接入技术对比

| 技术 | 传输介质 | 复用方式 | 调制方式 | 特点 |
|:---|:---|:---|:---|:---|
| **ADSL** | 双绞线 | FDM | DMT(多载波QAM) | 非对称，上行640kbps-6.4Mbps，下行32kbps-640kbps，距离受限 |
| **HFC** | 光纤+同轴电缆 | FDM | QAM | 共享介质，下行3-30Mbps，上行0.2-10Mbps，广播为主 |
| **FTTx** | 光纤 | TDM(WDM) | 光调制 | FTTH/FTTB/FTTC，带宽大，未来趋势 |
| **GSM** | 无线 | FDM+TDM | GMSK | 200kHz子信道，8时隙/TDM帧 |
| **5G** | 无线 | OFDM+Massive MIMO | 高阶QAM | 高频段(3.3-5GHz)，微基站，D2D通信 |

**ADSL vs HFC 性能对比：**

| 特性 | ADSL | HFC |
|:---|:---|:---|
| **介质独占性** | 用户独占双绞线 | 多用户共享同轴电缆 |
| **数据率稳定性** | 仅与距离/线径有关 | 与用户数、线路质量有关 |
| **上行方式** | 专用时隙 | 竞争方式(S-ALOHA/CDMA) |
| **对称性** | 非对称 | 非对称（下行为主） |
| **语音分离** | POTS分离器 | 频谱分割 |

## 八、核心考点小结

### 必须掌握的概念
1. **物理层四大特性**：机械、电气、功能、过程
2. **奈奎斯特定理**：无噪声，C = 2B log₂V，码元速率上限2B
3. **香农定理**：有噪声，C = B log₂(1+S/N)，绝对极限
4. **编码对比**：NRZ/NRZI/曼彻斯特/差分曼彻斯特的波形、自同步能力、带宽效率
5. **调制技术**：ASK/FSK/PSK/QAM的原理与权衡
6. **复用技术**：FDM/TDM/CDM/WDM/OFDM的原理与适用场景

### 计算题重点
- 信噪比dB与S/N比值转换：SNR(dB) = 10log₁₀(S/N)
- 奈奎斯特极限数据率计算
- 香农极限数据率计算
- T1/E1/SONET速率计算与开销分析

### 系统分析题
- ADSL/HFC/FTTx的组成、调制方式、复用技术对比
- 光纤单模/多模区别与选用场景
- CDMA码片序列正交性验证与扩频原理
